🕌 Java Lyrics Animation Project

Project Title

Lyrics Animation using Java Swing

Project Description

This project is developed using Java Swing. The application displays the lyrics of the Islamic song "Kardo Karam" one line at a time. Each lyric appears with different text colors and large font sizes. A Swing Timer creates an animation effect by changing the lyrics every few seconds.

Features

  • Java Swing GUI
  • Animated Lyrics
  • Multiple Text Colors
  • Large Font Size
  • Dark Background
  • Automatic Loop Animation

Technologies Used

Technology Purpose
Java Main Programming Language
Swing GUI Development
JFrame Main Window
JLabel Display Lyrics
Timer Create Animation

Output

The application opens a window titled "🕌 Kardo Karam". The lyrics are displayed in the center with different colors. Every 2.5 seconds, the next lyric appears automatically, giving an animation-like experience.
